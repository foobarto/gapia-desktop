# Changelog

All notable changes to Gapia Desktop will be documented in this file. The
project follows [Semantic Versioning](https://semver.org/) and uses the
categories from [Keep a Changelog](https://keepachangelog.com/).

## [Unreleased]

### Added

- Standard `1920x1080` and ultrawide `3840x1080` VITURE Beast display modes.
- Anchored 3DoF, smooth-follow, and 0DoF tracking controls where supported.
- Screen-size and distance controls with strict JSON configuration.
- GNOME primary-display and built-in-display privacy policies with layout
  verification and restoration.
- GTK 4/libadwaita settings application with live device information.
- GNOME Shell panel indicator and application icons.
- Idempotent host setup for atomic Fedora-family GNOME systems.
- SDK-free GitHub Actions releases and optional Homebrew source integration.
